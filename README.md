# SOFTWARE DE GESTÃO

**Status:** Finalizado
**Data de conclusão:** 25/09/2026
**Desenvolvimento:** Voluntário

## 1. Sobre o projeto

Software de gestão desenvolvido voluntariamente com o objetivo de auxiliar na organização e gerenciamento das atividades da instituição.

O sistema foi desenvolvido para execução local, utilizando um servidor acessível por `localhost`.

## 2. Tecnologias utilizadas

* **Python** — linguagem principal de desenvolvimento.
* **Flask** — framework utilizado para desenvolvimento da aplicação web.
* **HTML/CSS** — interface e apresentação do sistema.
 
## 3. Características

O software possui uma arquitetura baseada em aplicação web local, permitindo que o usuário acesse o sistema através de um navegador enquanto a aplicação Flask é executada localmente.

O projeto foi desenvolvido de forma voluntária, desde a implementação até a finalização e disponibilização do sistema para uso local.
